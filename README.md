# Cardbool Production Starter

Production-oriented starter for Cardbool.com.

Domains:
- cardbool.com
- www.cardbool.com
- app.cardbool.com
- admin.cardbool.com
- api.cardbool.com

Deployment order:
1. Put this project in the owner's source repository.
2. Create the production PostgreSQL/Supabase project.
3. Apply database schema and security policies.
4. Deploy the API and web services.
5. Add the custom domains in the hosting dashboard.
6. Enter the exact DNS targets supplied by the hosting provider into CSC.
7. Enable MFA, backups, monitoring, rate limiting and security controls.
8. Complete legal/compliance and payment-provider review.
9. Only then enable real customer payouts.

This starter does not process real money, verify real gift cards, or contain production secrets.
